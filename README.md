# Portofolio Rangga Figo Hidayat

Portofolio pribadi Rangga Figo Hidayat — Full-Stack Web Developer dari Demak.

- **Stack:** Next.js 15 (App Router) + React 19 + TypeScript
- **Animasi:** anime.js — stagger hero, scroll reveal, counter statistik, dan efek gambar stroke-by-stroke (doodle line-art yang digambar garis demi garis, ala anidoodle)
- **Palet:** hitam, putih, abu, navy
- **Deploy:** Vercel, terhubung ke repo ini — setiap push ke `main` auto-redeploy.

## Jalankan lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000

## Struktur

- `app/page.tsx` — seluruh halaman (hero, tentang, proyek, pengalaman, keahlian, kontak)
- `app/globals.css` — semua styling
- `public/` — foto, CV, dan screenshot proyek
